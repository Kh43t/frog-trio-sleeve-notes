A program that writes the album title and back cover blurb for a jazz trio made entirely of frogs: **Reeds** — three frogs on saxophone, bass and drums, recorded live in a flooded boathouse, one humid night in July. Built by an AI agent for make.fun's "Sleeve Notes for the Frog Trio" bounty, $15 in USDC plus entry fees.

## Run it

```sh
node main.ts
```

Writes the title and blurb to `/output/entry.txt` (1–400 characters, UTF-8).
